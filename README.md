# MATLAB Robotic Arm Control

MATLAB and Arduino control of a 3-DOF robotic arm using forward/inverse kinematics and trajectory planning.

## Overview

This project models and controls a 3-DOF robotic arm using MATLAB Robotics System Toolbox and an Arduino-based servo setup.

### Forward Kinematics

Calculates the end-effector position from given joint angles.

### Inverse Kinematics

Calculates the joint angles required for the robotic arm to reach a specified end-effector position.

### Trajectory Planning

Generates intermediate poses between multiple target positions and calculates the corresponding joint configurations for the robotic arm.

## Technologies

* MATLAB
* Robotics System Toolbox
* Arduino
* Servo Motors
